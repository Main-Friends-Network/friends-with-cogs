# friends-with-cogs

This is the modpack repository for the "Friends with Cogs" server.

`instance/` contains the Prism Launcher instance config. This folder can be zipped (.zip) and imported into Prism Launcher.

`packwiz` contains the packwiz configuration for the modpack itself. This can be managed with packwiz.

## How to launch

1. Open Prism Launcher
2. Select "Create instance" in the top left
3. Select "Import"
4. Select the friends-with-cogs.zip file
5. Name the instance "Friends with Cogs"
6. Run the instance
